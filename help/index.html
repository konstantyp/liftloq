How to use Liftloq

Local workout calendar · No account required · Dark theme only · Updated for version 2.7.2

Liftloq keeps your workout plan on your device. Mark days on the calendar, manage workout types, plan and time HYROX workouts, and optionally track supplement spending — without signing in.

1. Mark a workout on the calendar

  1. Open Calendar (home).
  2. Tap a day (or the add button). The day sheet has collapsible Bodybuilding, HYROX workouts and Notes sections.
  3. Pick up to three entries in total (Bodybuilding types and HYROX workouts combined). At 3, the other picks are disabled until you deselect one. HYROX rows have a checkbox: a picked row says Tap to unselect; tap it again to remove it.
  4. Tap Save. Nothing is stored until you save. Clear day, Cancel and Save float in a bar at the bottom of the sheet; everything scrolls up clear above it, Notes included (also with the keyboard open).
  5. Save an empty day: to remove a workout, unmark it (tap its chip, or a HYROX row’s checkbox) and tap Save. Save works even when the day ends up with nothing selected; the day’s workouts are cleared and its note stays unless you clear the note too. On a new day with nothing picked, Save stays off. Clear day removes everything at once, note included.
  6. The day shows one colour band per entry: Bodybuilding first, then HYROX.
  7. Jump to a month: tap the month name at the top (it has a small ▾ arrow). Go to month opens with the year and all 12 months: the month you are looking at is filled, today’s month is outlined. Use ‹ › to change the year, then tap a month to jump there. This month jumps back to today; Cancel keeps the calendar where it was. The ‹ › arrows next to the title and swiping left or right on the month still move one month at a time.
  8. The menu button is the kettlebell at the top left of each page (in One-handed mode it is at the bottom; see One-handed mode).

2. Add and remove Bodybuilding types

  1. Open the menu → Bodybuilding. Or on a day sheet, tap Manage types.
  2. To add: tap +, enter a name, pick a color, then tap Save.
  3. To remove: tap the trash icon on a type, then confirm Delete.

3. Advanced bodybuilding (exercises on workout types)

  1. Bodybuilding has two modes. Simple (default) works exactly as before: you mark a day with a workout type, and a type has only a name and a colour. Advanced also lets you keep exercises on each workout type and log sets, reps and kg.
  2. Turn it on in Settings → Modes: under Bodybuilding, tap Advanced. The switch is only shown while Bodybuilding is on.
  3. Add exercises to a type once: menu → Bodybuilding, tap a type (or + for a new one). Below the colour there is Exercises. Tap + Exercise and pick one from the list, grouped by muscle (Chest, Back, Shoulders, Biceps, Triceps, Legs, Calves, Core). Tap an exercise to set how many sets it has (1–20, for example “Chest · 3 sets”); the Sets field always shows the number that is saved. Use ⋮ to move it up or down, and the red trash button to remove it. Then tap Save.
  4. On a day, open the Bodybuilding section and pick the type. Its exercises are already there, with empty sets. The first exercise is open: fill in reps and kg, and add more with + Set. A set counts as done as soon as you enter reps or kg; an empty set is not done. The summary shows how many sets are done and your best kg. Tap a card to open or close it. With two types picked, each type’s exercises follow in chip order.
  5. Doing something extra today? Tap + Exercise for this day. It is marked This day only and does not change the type.
  6. Tap Save on the day sheet to keep the day and its sets. If you change a type’s exercises later, days you already logged stay as they were.
  7. Missing an exercise? At the bottom of the list, tap + Custom exercise, enter a name, choose the muscle group and tap Save. It is listed in its group from then on.
  8. Logs from version 2.3.0 are kept as This day only exercises, and each type starts with the exercises of its most recent logged day. Switching back to Simple only hides all of this; nothing is deleted. Unmarking a type on a day and saving removes that type’s exercises from the day (This day only exercises stay). Clear day in Advanced mode also clears that day’s exercises.

Last time and records

  1. In Advanced mode, an open exercise card on a day shows Last: the date and sets (kg × reps) of the last earlier day you logged that exercise, for example “Last · Fri 16 Oct · 80×8 · 80×8 · 82.5×6”. If you have never logged it before, there is no Last row.
  2. Copy last (next to + Set) fills only the empty set rows from that last session, set by set: set 2 gets last time’s set 2, and so on. Sets you already typed are never changed, and no rows are added. The button is greyed out when there is no last session or nothing left to fill. Cancel still discards it.
  3. A PR badge under a set number means a new personal record: that set’s kg is higher than your heaviest set on any earlier day. Only the heaviest set of the day gets it; matching your best is not a PR, and your first session never has one.
  4. Tap the history button on the Last row to see every session of that exercise, newest first, grouped by month, with your best top set at the top. Sessions that set a record carry the same PR badge.

4. Track supplements (Supps cost)

  1. Open the menu → Supps cost.
  2. Tap + to add a purchase (name, price, date), then tap Save.
  3. Set currency under Settings (same menu).
  4. See Total spent on supplements and the Money spent list.
  5. Don't need it? Turn off Supps cost in Settings → Modes; the page leaves the menu and the swipe cycle, and your purchases are kept.

5. HYROX

  1. Builder: menu → HYROX → +. Name the workout, pick a colour and division, then tap + Segment to pick a run or station from the list (sorted into Runs and Stations). While the list is still empty, + Full race next to it adds the 16 official segments. A new segment opens ready to edit (distance or reps, weight); tap any card to open it, use ⋮ → Move up / Move down to reorder, and the red trash to delete it (you confirm first). The list scrolls under the floating Cancel and Save buttons (bottom right). If the name is empty, Save scrolls back to the Name field and shows Name required. When editing an existing workout, Delete is next to the title.
  2. Delete: on the HYROX list, tap the red trash on a workout (or Delete inside the editor). Confirm — sessions are removed and the workout is cleared from every calendar day. Official race is not re-seeded after you delete it.
  3. Plan it: on a day sheet, open HYROX workouts and pick one or more, then Save.
  4. Start HYROX: on a day with a planned HYROX workout, a Start HYROX button appears above the add button. With several planned, it opens a menu to choose one.
  5. Race mode: a wavy progress bar and the big total sit on top, then a Current card (segment and its time), a Next card (with your best split when known) and every finished split, newest first, vs your best (scroll to see them all). Tap Next split at the end of each segment. Pause freezes the clock (paused time is not counted; the wave goes flat), Resume continues, the undo button removes the last split. All three sit in one connected row that floats at the bottom of the screen; the list scrolls underneath it, and the last split scrolls clear above it. Finish (top bar) asks for confirmation. Then review and Save; results show with an OK button back to the calendar.
  6. Stats: Stats → HYROX shows History (tap a session for its results), best splits and station decay. History is newest first; sessions on the same day stay in the order you did them, also after an export/import.

6. Stats

  1. Menu → Stats. The bottom toggle has Days since (opens first), Overview, HYROX (only while HYROX is on) and Progress (only in Advanced bodybuilding). While Progress is there, the toggle shows icons only.
  2. Days since shows how long ago you last did each type: green 0–3 days, yellow 4–6, red 7 or more (or never).
  3. Overview shows this week or month by type; HYROX shows History, templates and best splits.
  4. Swipe up to go to the next tab: Days since → Overview → HYROX → Progress → Days since. Long tabs scroll normally first; the tab only changes when you keep swiping up at the bottom. The toggle follows.

Progress (Advanced bodybuilding)

  1. Stats → Progress (the chart icon, last in the toggle) charts one exercise over time. Pick it under Exercise; the list only has exercises you have logged with at least one filled set. It starts on the one you logged most recently.
  2. Top set (default) is your heaviest kg on each day. Volume adds up reps × kg for the day. Estimated 1RM estimates your one-rep max from sets of 1–12 reps. Empty sets don’t count, and a day without a value is simply skipped.
  3. Below the title: Best, Latest and Change (in kg and %) for the chosen range. Choose the range with 4W · 3M · 6M · 1Y · All (3M first). Tap a point on the chart to see its date and value.
  4. Under the chart, 3–4 dates are spread evenly across the range: the first and the last session always, and evenly spaced dates in between, so even a short range of a few days shows several dates. If there isn’t room at a larger text size, fewer dates are shown so they never overlap. For 1Y and All, when the range crosses into a new year, the dates show month and year (for example Nov 25).
  5. Exercises without kg (for example pull-ups) show Max reps instead, and Volume becomes total reps. With only one session there is a single dot and “Log another session to see a trend.”

7. Settings: sections and toggles

  1. Menu → Settings. Sections: General (language, currency, theme, one-handed mode, motivation quote), Modes, Card order, Workout plan and About.
  2. Theme: Settings → General → Theme lets you choose Purple (default), Lavender, Rose or Red. Pick a theme and tap OK; the row shows your choice as unsaved. Tap Save to apply it: the app reloads in the new theme and both home-screen widgets follow. Leaving Settings without Save keeps the current theme. Liftloq is dark-only: every theme is dark, even when the phone is set to light mode.
  3. Modes: turn Bodybuilding or HYROX off to hide everything for that mode (calendar entries, legend, stats, menu pages). Nothing is deleted; turning it back on restores it. One of the two must stay on. Supps cost has its own switch, separate from that rule: off hides the Supps page from the menu and swipe cycle (purchases are kept).
  4. Card order: use the ↑ / ↓ buttons to set the order of the cards in the menu and in the swipe cycle. Changes apply right away. Cards switched off in Modes are dimmed and marked Hidden; you can still move them, and they are skipped until you turn them back on. Settings is always last in the menu and is never part of the swipe cycle.
  5. A language, theme or one-handed mode change is applied when you tap Save.
  6. About: Settings → About → About Liftloq shows the app version (name and build number). Help & feedback opens this page (How to use) or an email to the developer (Feedback); Legal has the Privacy policy.

One-handed mode

  1. Settings → General → One-handed mode (right under Theme) moves the menu to the bottom of the screen, within reach of your thumb. It is off by default.
  2. Turn the switch on: the row shows unsaved. Tap Save to apply it; the app reloads with the new layout. Leaving Settings without Save keeps the current layout. Turn it off the same way.
  3. When it is on, every main page (Calendar, Bodybuilding, HYROX, Stats, Supps cost and Settings) has one button at the bottom centre, always in the same place. Its left half (the kettlebell) opens the menu; its right half is the page’s main action, the same as the round button in normal mode: add a workout today on the Calendar, and + on Bodybuilding, HYROX and Supps cost. Stats has no main action, so it shows only the menu button, below the Stats tabs. Settings shows only its Save button in that place (with the word Save while you have unsaved changes); press Back to leave Settings.
  4. The menu opens as a panel from the bottom with the same pages as before. Swipe it down, tap outside it or press back to close it. In this mode the menu does not open by swiping in from the left edge; the other swipes (swiping up at the end of a list, swiping left below the calendar to the next card) work as before.
  5. The top-left menu button is hidden in this mode. Lists scroll underneath the bottom button, and the last item can always be scrolled clear of it. Start HYROX on the Calendar sits above it. During a HYROX race the race buttons are shown instead.

8. Export / import

  1. Settings → Workout plan → Export workout plan saves a JSON backup (types, days, notes, supplements, HYROX data, your card order and Modes switches, and the Advanced bodybuilding data: the exercises on your workout types, the exercise log and your custom exercises). The colour theme is a setting on this phone and is not included.
  2. Import workout plan replaces your data from such a file, after a confirmation. Days with more than 3 entries keep the first 3. Files from older versions have no card settings, so the default order is used and all cards are turned on. They also have no Advanced bodybuilding data: Bodybuilding is set to Simple and your exercise log on this phone is kept. Files from 2.3.0 have no exercises on workout types, so the ones on this phone are kept.

Auto export

  1. Settings → Workout plan → turn on Auto export. Android’s folder picker opens (in Documents): open or create a folder, for example Liftloq, tap Use this folder and allow access. If you cancel, Auto export stays off.
  2. Liftloq writes one file there, liftloq-backup.json, right away and again right after every change: days, types, notes, HYROX, the bodybuilding log, purchases and the settings that are part of the backup. It is the same file as Export workout plan, so Import workout plan can restore it. The file is replaced each time; no dated copies pile up.
  3. Change folder (shown while Auto export is on) picks another folder. It also shows when the last auto export happened.
  4. Turning Auto export off stops the backups and gives back the folder access; the file already written stays.
  5. The backup also includes the Auto export settings (on or off, the folder and the last export time). When you import it on the same phone, Auto export goes back to that folder. On a new phone (or if Liftloq can no longer use that folder) Auto export stays off and shows Folder access was removed. Turn on to choose a folder again.: turn it on and pick the folder again. Files from older versions don’t have these settings, so importing them leaves Auto export as it is.
  6. If the folder is deleted or Liftloq’s access to it is removed, Auto export turns itself off and shows Folder access was removed. Turn on to choose a folder again.
Tip: Swipe left below the calendar to cycle through the cards in your Card order (default: Calendar → Bodybuilding → HYROX → Stats → Supps cost). Pages for a mode that is off are skipped. Settings stays in the menu only.
